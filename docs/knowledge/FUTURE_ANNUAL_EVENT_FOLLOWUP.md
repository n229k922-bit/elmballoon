# 将来案：周年・誕生日等の翌年フォロー

## 決定事項（2026-10-19）

ユーザー意向：現段階では実装しない。良いアイデアとして保管する。

状態：アイデア保管のみ・実装保留。定期実行、通知予約、顧客送信を開始しない。この記録は実装・送信の許可ではない。

## アイデア

過去の周年祝い・誕生日・イベント注文を参考に、翌年の時期が近づいた際にフォローを支援する。

1. 店長向け候補：前回の注文写真、商品、当時の金額、お届け先、今年確認したい事項をまとめて、準備や接客の参考として案内する。
2. 顧客向け候補：店長が希望し、連絡可否・対象・文面・時期を確認した場合に限り、今年の相談を案内する。店長向け通知とは別機能とする。

## 再検討時の条件

- 記念日・開催日・配達日を区別し、前年の配達日から記念日を推測しない。
- 毎年開催か、今年も連絡してよいかを確認。過去の注文だけを継続契約・営業連絡への同意と扱わない。
- 移転・閉店・担当者変更、弔事など連絡に配慮が必要な事情、連絡停止希望を考慮する。
- 前年の価格・在庫・配送条件・年齢・周年数を自動確約しない。
- 重複案内を防ぎ、停止・取消ができる仕組みを検討する。
- 実装開始と、実際の対外連絡は改めてユーザーへ確認する。

現在優先する範囲は、再注文や相談が来たときに過去カルテ・お届け先を店長が参照できるよう整理すること。翌年フォローはその範囲へ混ぜない。
