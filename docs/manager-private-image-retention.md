# 注文参考画像の非公開保存

店長認証を通った画面だけが、注文・顧客・発言の一致を確認して画像を参照します。画像の個数・文字・仕様を自動確定しません。顧客チャネル以外のトークンで取得しません。

`manager-image-archive.js` は `env.SECRETARY_KV` の非公開領域に画像バイナリと検証用状態を保存します。キーは `manager:image:v1:<SHA-256>` と `manager:image-state:v1:<SHA-256>` です。注文・顧客・発言・LINE画像ID・customer区分の組合せから作り、画像と状態が一致し内容ハッシュを検証した場合だけ再利用します。公開画像URLは作成しません。

保存期間は保存時点から365日（`IMAGE_RETENTION_SECONDS`）です。人物・名前・住所などの個人情報が画像に含まれる場合もこの保持期間が適用されます。保持期間を変える場合は、顧客向け個人情報の取扱い案内も合わせて確認します。KVのバックアップには画像・検証状態・走査位置を含める必要があります。バックアップコピーを残す期間はバックアップ側の保持方針に従うため、KVのTTLによる削除だけではバックアップ内から削除されません。

自動保存は処理済みかつ注文に関連付けられた顧客画像を巡回し、1回最大5件を取得します。LINEへの接続は1件5秒、最大8MiB、PNG/JPEG/GIF/WebPのMIMEとファイル署名を検証します。自動再試行は3回までで待ち時間を設けます。店長が個別に画像を開く操作は再試行できます。KV設定・権限・顧客トークンが不足する場合、自動保存は理由付きでスキップします。

PNGはCRCだけでなくzlibデータを上限付きで展開し、各行のフィルター値と展開データ長を確認します。展開後32MiB以下・非インターレースの画像が対象です。対象外のPNGは壊れた画像として保存せず、原本での確認を案内します。ブラウザ側でも表示失敗を検出して明示します。カルテPNG出力は900px幅・最大7.2百万画素・190行・本文2万文字を上限とし、超過時は一部だけの画像を作らず印刷用HTMLで全文確認するよう案内します。

画像表示時も保存済み画像を先に利用し、未保存ならLINEから取得して保存を試みます。保存に失敗しても今回の表示が可能な場合は `X-Image-Archive-Status: failed` で長期保存失敗を区別します。LINEから既に削除・期限切れとなり保存もない画像は `image_expired` です。未取得画像を復元・生成したことにはしません。過去に保存できなかった画像は元のトークや原本で確認が必要です。
