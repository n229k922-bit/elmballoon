# 注文担当の拡張監査（2026-10-16）

合成発言だけを用いたローカル読取・局所再現。実LINE送信、DB変更、ソース修正は行っていない。実個人情報・非公開顧客意図は参照も転記もしていない。再現は `planConversation`、`startsNewOrder`、`chooseOrder` の直接呼出しであり、全文Webhook・DB書込み・送信を通した結果とは区別する。

## 判定

現行の通常注文聞き取りには一定の保護があるが、脱線・見送り・非定型クレーム・安全事故・1通内複数注文について、合成役割対話と同等の応答能力は確認できない。複数の不合格を再現した。本番応対能力の合格とはしない。

## コード根拠

- `workers/admin-line-secretary/src/conversation.js:48`：新注文認識は文頭固定。文中の「あと別件」を扱わない。
- `workers/admin-line-secretary/src/manager-runtime.js:88`：振分は1メッセージ群→1注文。開いている注文1件ならその注文へ寄せる。複数注文だと曖昧保留できる点はよいが、1通内で旧注文追記＋新注文作成を表現できない。
- `workers/admin-line-secretary/src/manager-runtime.js:169`：開いている相談だけを検索。終了後のお礼でも、終了意図判定前に新しい相談が生成され得る（`chooseOrder` の注文0件は create）。全文実行での追加検証が必要。
- `workers/admin-line-secretary/src/manager-runtime.js:202`：注文選択後、発言全体の抽出結果をフィールド更新へ流す。意味的に一部が曖昧でも他項目は更新される。
- `workers/admin-line-secretary/src/conversation.js:165`：用途が分からない単独の日付を `receive_date` へ割当てる。
- `workers/admin-line-secretary/src/conversation.js:198`：例外検出は「変更・キャンセル・返金・間違・届か・まだ来」の語中心。見送り・責任者要求・誤飲は対象外。
- `workers/admin-line-secretary/src/conversation.js:226`：質問と判断理由が空だと一律 `review_collected_details`。終話、挨拶、無関係質問が正常な無処理として終われない。
- `workers/admin-line-secretary/src/manager-runtime.js:239`：自動受付から「破損・怪我・苦情・返金」等を除外する保護はある。ただし非定型表現の網羅性、安全専用返信と優先通知は別問題。
- `workers/admin-line-secretary/src/manager-runtime.js:264`：「今日・明日」で急ぎ判定。無関係な発言でも期限へ影響する可能性。

## 実ナレッジとのギャップ

匿名化済み `REAL_CONVERSATION_KNOWLEDGE.md` を確認。`docs/order-knowledge-import.md` に記載の私有カルテ原文は読まず、個人情報を合成記録へ移していない。

- 実会話知見は「リピーターの新規相談は別注文」「住所・価格を引き継がない」「用途と受取日を分ける」「短文は適切に統合」「既回答は再質問しない」とする。多くは通常文のテストがあるが、文中複数注文や脱線で破れる。
- `BALLOON_CARE_KNOWLEDGE.md:66` は火気・破裂・薬品・吸引で安全案内を先にする方針。今回の受付エンジンはこの方針の参照・分類を保証しない。
- `docs/order-knowledge-import.md` 自体が、過去価格・配達範囲・在庫・制作日数を確約へ自動昇格しない、実カルテ候補は要レビューと明示。合成店長が価格を答えたことは本番根拠にならない。

## 推奨する合格テスト

1. **対話意図ゲート**：注文更新・新相談・見送り・成立注文取消・苦情・人へ交代・安全・終話・雑談・曖昧を抽出より先に判定する。
2. **更新禁止の既定値**：雑談・安全・苦情・終話では注文事実を更新しない。曖昧な複数注文は一部フィールドだけ書かない。
3. **文中複数注文**：旧ブーケと新スタンドの独立フィールド・承認・送信、2注文を明示して確認する。商品明細と別注文も区別する。
4. **見送りのライフサイクル**：未確定相談は顧客意図に応じ終了候補へ。お礼は注文を作らず、再開は明確な新依頼で行う。成立注文のキャンセルは店長判断へ。
5. **非定型クレーム**：「最悪」「話が違う」「責任者」でも自動聞き取りを停止。人への通知が通常の営業時間待ちに埋もれない。
6. **安全優先**：曖昧な危険表現も安全側へ。専門レビュー済み短文と優先連絡、誤飲相談を注文確認の笑顔文面にしない。
7. **継続的な回帰**：同一意図を敬語・口語・誤字・絵文字・分割・訂正で変形し、注文フィールド不変、対象正確、不要通知0、未確定維持をアサート。

この監査ではソースを変更していない。局所結果は改善仮説ではなく現在の関数出力として再現したが、実LINE到達性の証明ではない。
