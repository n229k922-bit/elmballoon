- 緊急案件を通常20件の境界の後ろへ放置しない。同一顧客内の発言順は維持。
- 弔事・お悔やみ・お供えは初回AI開示を含め控えた文面にし、後続も人による確認を維持。

- 現在の注文・顧客に限定した直近40件の会話履歴から、写真共有拒否後の写真提案を抑止。
- 終話の旧テスト期待を新仕様へ整合。終話に注文変更が付く場合の回帰も追加。
